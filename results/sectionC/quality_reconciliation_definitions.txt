coverage_1to1 (manuscript selection metric, scripts/toga_species_coverage.py): numerator = alignment files in which the assembly has exactly one sequence; denominator = all readable *.fasta.gz alignment files (human hg38 genes). TOGA's multiple codon alignments contain intact orthologs only, so partly intact or lost genes do not count.
intact_share_loss_matrix (results/sectionC/feasibility_toga.csv): numerator = genes of the 115-species loss matrix whose most intact transcript is I or PI in TOGA's loss_summ_data; denominator = all 19,457 genes of that matrix (genes without a projection count as missing). Partly intact genes count as intact.
Exception: trait species were added by name and need not pass coverage >= 0.85 (scripts/toga_select_species.py); Ellobius_talpinus (0.835) entered this way.

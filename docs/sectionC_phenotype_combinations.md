## Feasibility conclusion (for the authors' decision)
1. On eye morphology, a vision-versus-habitat contrast exists only through *P. minor* (one lineage, probably
   species-matched, fragmented assembly). Any result could be driven by this single lineage; the planned analysis
   would need to report it with and without *P. minor*, and with the boto coded unknown.
2. The opposite contrast (subterranean without eye regression) has no supported lineage at present; it depends on
   species-matched evidence for *C. sociabilis* (or *Rhizomys*).
3. On image-forming vision, states are mostly unknown; only a graded contrast (impaired versus unknown) is available.
4. The predictors therefore cannot yet distinguish visual regression from habitat beyond a single-lineage,
   exploratory comparison. The limitation is phenotype evidence and independent transitions, not genome number.
